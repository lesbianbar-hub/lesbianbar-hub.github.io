# Beiträge hinzufügen

Um einen neuen Beitrag hinzuzufügen, folge diesen Schritten:

1. Klicke auf „Add file“ → „Create new file“
2. Gib den Dateinamen im Format `YYYY-MM-DD_Titel.md` ein, z. B. `2025-04-05_letzter-Tag-im-archiv.md`
3. Schreibe deinen Beitrag in Markdown-Format (siehe Beispiel unten)
4. Klicke auf „Commit new file“

---
